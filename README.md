# fantasy-baseball-keeper-league-tool

A private, noncommercial analysis tool for one 12-team Yahoo Fantasy Baseball keeper league. The project is in development and is used by one league operator; reports may be shared with league members.

The tool requests read-only Yahoo Fantasy Sports data, including league settings, teams, rosters, player statistics, standings, matchups, and transactions. It uses that data to maintain season records, prepare commissioner reports and weekly payout calculations, and review roster and keeper rules.

The tool does not change Yahoo rosters, transactions, or league settings. It has no public signup.

Fantasy data provided by [Yahoo Fantasy](https://sports.yahoo.com/fantasy/).
